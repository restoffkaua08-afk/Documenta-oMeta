# Checklist de Manutencao Documental

## A cada mudanca tecnica

- [ ] atualizar a especificacao afetada;
- [ ] atualizar status e proxima acao;
- [ ] registrar branch, commit, testes e build;
- [ ] revisar riscos e contratos;
- [ ] criar ou substituir decisao quando necessario;
- [ ] atualizar resumo somente depois da fonte tecnica;
- [ ] preservar entendimento anterior como superado quando relevante.

## Antes de integrar documentacao

- [ ] todos os arquivos documentais estao em `docs/`;
- [ ] nenhum README foi criado;
- [ ] links relativos existem;
- [ ] indices apontam para os documentos novos;
- [ ] termos seguem o glossario;
- [ ] planejado nao aparece como implementado;
- [ ] segredos, tokens e dados pessoais nao foram incluidos;
- [ ] datas, branches e commits foram conferidos;
- [ ] contradicoes foram resolvidas ou marcadas `a confirmar`.

## Ao fechar uma etapa

- [ ] criterios de aceite avaliados;
- [ ] evidencias reproduziveis registradas;
- [ ] riscos residuais aceitos explicitamente;
- [ ] decisao do gate documentada;
- [ ] proxima etapa autorizada;
- [ ] matriz geral de gates atualizada.
