# Zane - Roadmap e Gates

## Z0 - Consolidation Ready

Inventarios, releases standalone, matriz de capacidades, contratos e decisoes de migracao.

## Z1 - Core e Cloud MVP

Dominio, API, runtime basico, auth, banco/migrations, web chat, observabilidade inicial e deploy de staging.

## Z2 - Desktop Agent MVP

Tauri, runtime local, vault, tools locais, approvals, streaming, installer e updates iniciais.

## Z3 - Multi-tenant e Sync

RLS, isolamento, dispositivos, sync offline, conflitos, exportacao e exclusao.

## Z4 - Agent Runtime completo

Planner, tools, skills, jobs, browser governado, MCP, verificacao, budgets e cancelamento.

## Z5 - Production Beta

Testers convidados, seguranca, backup/restore, monitoramento, custos, suporte e incidentes.

## Z6 - ULTRON Compatibility

Extension Manager, install/activate/rollback, namespaces e prova de opcionalidade.

## Z7 - Mobile MVP

Chat, approvals, notificacoes e acompanhamento, conforme prioridade futura.

## Z8 - Hardening

Performance, acessibilidade, resiliencia, supply chain, privacidade, migracoes e releases.

## Z9 - Zane 1.0

Produto completo, independente, documentado e operacional.

## Gate de independencia

- nenhum import/processo Rachel/Jarvis obrigatorio;
- Zane inicia com ULTRON offline;
- capacidades essenciais possuem implementacao/testes nativos;
- dados dos predecessores entram apenas por migracao;
- licencas e proveniencia preservadas;
- rollback de deploy e migration testado.

## Estado atual

Especificacao. Nenhum gate Z esta verde antes da construcao e das pre-condicoes dos predecessores.
