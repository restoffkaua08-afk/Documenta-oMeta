# Glossario do Projeto Meta

| Termo | Definicao |
|---|---|
| Meta | Programa de engenharia que organiza Rachel, Jarvis, ULTRON e Zane |
| Rachel | IA/agente pessoal standalone e predecessora cognitiva do Zane |
| Jarvis | Runtime agentic standalone derivado do OpenJarvis |
| ULTRON | Plataforma opcional de capacidades versionadas |
| Zane | Produto final independente criado pela consolidacao dos predecessores |
| Standalone | Capaz de instalar, iniciar e cumprir seu escopo sem outro projeto do Meta |
| Consolidacao | Processo de selecionar, redesenhar e unificar capacidades em arquitetura propria |
| Wrapper | Camada fina que apenas chama outro sistema; nao descreve o Zane final |
| Runtime | Camada que recebe solicitacoes, coordena modelos/tools e produz resultados/eventos |
| Agent Loop | Ciclo de observar, planejar, autorizar, executar, verificar e continuar/encerrar |
| Tool | Operacao tipada capaz de ler ou produzir efeitos |
| Skill | Capacidade composta por instrucoes, tools e/ou fluxo reutilizavel |
| Workflow | Sequencia declarativa de passos e condicoes |
| Pack | Unidade versionada que agrupa capacidades no ULTRON |
| MCP | Protocolo de integracao de ferramentas e contexto |
| Model Router | Componente que escolhe provider/modelo conforme capacidade, politica e custo |
| Local-first | Modo em que dados e funcoes essenciais permanecem disponiveis localmente |
| Gate | Conjunto objetivo de criterios e evidencias para liberar uma fase |
| Readiness | Nivel comprovado de preparacao para um escopo especifico |
| Architecture Closed | Arquitetura documentada/fechada; nao equivale a Production Ready |
| Professional Agent Ready | Criterio final do novo roadmap profissional da Rachel |
| Evidence | Artefato verificavel que sustenta uma afirmacao |
| Cyber | Responsabilidade de seguranca e autorizacao no desenho da Rachel |
| Ned | Responsabilidade de planejamento, pesquisa e raciocinio no desenho da Rachel |
| Arya | Responsabilidade de operacao governada no desenho da Rachel |
| Dany | Responsabilidade de avaliacao/qualidade nos documentos da Rachel |
